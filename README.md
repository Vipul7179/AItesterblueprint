\# AI Automation Testing Frameworks



A collection of automation testing frameworks developed using modern automation technologies.



\## 1. Playwright Automation Framework



\- \*\*Technology:\*\* Playwright, TypeScript, Node.js

\- \*\*Project folder:\*\* `PlaywrightFramework/`

\- Page Object Model (POM)

\- Accessibility-first locators

\- UI automation testing

\- Headed and headless execution

\- Custom reporting



\## 2. Selenium Automation Framework



\- \*\*Technology:\*\* Selenium WebDriver, TypeScript

\- \*\*Project folder:\*\* `SeleniumFramework/`

\- Page Object Model (POM)

\- Reusable automation utilities

\- Automated UI testing

\- Maintainable framework architecture
